## 🧠 Project Description

This project demonstrates the installation, configuration, and networking of **Ubuntu Operating System** using **VMware/VirtualBox**.  
It was developed as part of the **Operating Systems course** to gain hands-on experience with virtualization, OS installation, and server configuration.

The project includes:
- Installation of Ubuntu OS on VMware/VirtualBox  
- Creation of multiple virtual machines (Ubuntu 1 & Ubuntu 2)  
- Network configuration and testing using `ping` command  
- Basic server setup and configuration  

---

## 🛠️ Technologies & Tools Used

- **Operating Systems:** Ubuntu, Windows 10/11  
- **Virtualization Tools:** VMware Workstation, VirtualBox  
- **Concepts:** OS Installation, Virtual Machine Configuration, Networking, Server Setup
